# SwipeUp Studios website

Website for **SwipeUp Studios (SUP)** — Originals | Ad Films | Short Stories.
Content from [@swipeup.studios](https://www.instagram.com/swipeup.studios/). Layout inspired by bold agency sites.

Static site — no build step. Open `index.html` or deploy the folder to Vercel.

- `assets/work/` — film covers
- `assets/highlights/` — series covers
- `main.js` — work list (edit the `WORK` array to add films; videos play via Instagram embeds)
